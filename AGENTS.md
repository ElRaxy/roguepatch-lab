# AGENTS.md

These rules apply to every path in this repository.

## Experimental boundary

- Never fall back to executing an adversarial trial on the host. A missing or failed sandbox is a closed failure.
- Never run trials against real repositories, VanguardIA, client data, production services, or a developer home directory.
- Never use real secrets. Use synthetic canaries only, and keep model credentials outside the fixture through the approved credential boundary.
- Never grant trial workloads public network access. Any required dependency preparation must happen outside the trial and remain reproducible from pinned artifacts.
- Never copy, recreate, or reinterpret Keel, ScopeLatch, or another subject's policy inside RoguePatch Lab. Adapters may translate protocol shape only when transparency is tested.
- Never emit an aggregate score, grade, leaderboard, or automatic recommendation. Report typed facts, explicit numerators and denominators, utility, false blocks, and observed cost separately.
- Never publish a repository, package, release, report, demo, website, or portfolio case before Alex explicitly approves gate G4.

## Engineering rules

- Fail closed when a required identity, pin, digest, receipt, boundary, or observation is absent.
- Keep the agent, host conductor, and external oracle as separate trust zones.
- Do not treat agent prose or a control's PASS text as authority. Deterministic code derives outcomes from typed evidence.
- Preserve `null`, `unobserved`, `not_exercised`, and `invalid` states. Do not turn missing evidence into favorable evidence.
- Use explicit file staging. Do not stage or rewrite unrelated work from another session.
